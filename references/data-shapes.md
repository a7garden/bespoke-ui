# 데이터의 모양 → 형태

먼저 데이터가 어떤 모양인지 고르고, 그 모양이 자연스럽게 놓이는 형태에서 출발한다.
한 화면에 모양이 둘 이상이면 주인공 판단에 쓰이는 모양 하나를 고른다.

| 모양 | 알아보는 질문 | 흔한 기본안 | 먼저 떠올릴 형태 |
| - | - | - | - |
| 시간 흐름 | 「언제 · 얼마 동안 · 추세는」 | 날짜 칸이 있는 표 | 타임라인 레인 · 스파크라인 행 · 달력 열지도 · 지금 선이 있는 가로 축 |
| 순서와 단계 | 「지금 어디까지 · 다음은」 | 스텝퍼 동그라미 | 단계 레일(단계 폭 = 걸린 시간) · 칸반 열 · 지하철 노선도 |
| 기한 | 「얼마나 남았나 · 늦었나」 | 마감일 글자 + 빨간 배지 | 타들어 가는 기한 띠 · 지금 선 기준 앞뒤 배치 · 남은 날로 정렬된 레인 |
| 상태 전이 | 「어디서 어디로 넘어갔나」 | 상태 배지 | 상태 레일 위 점 · 전이 화살표 묶음(생키) · 상태별 칸에 놓인 토큰 |
| 비율과 구성 | 「전체 중 얼마」 | 도넛 | 비율 띠 한 줄 · 와플(100칸) · 쌓은 막대 |
| 크기 비교 | 「무엇이 더 큰가」 | 숫자 KPI 타일 | 한 축 위 점 · 정렬된 막대 행 · 크기 대비 칩 |
| 차이 | 「전과 무엇이 바뀌었나」 | 두 탭 · 두 표 | 전후 겹쳐 보기 · 밀어 보는 비교 렌즈 · 바뀐 칸만 밝히기 |
| 공간 | 「어디에 · 무엇 근처」 | 주소 글자 목록 | 지도 위 표식 · 거리 고리 · 목록과 지도가 서로 따라 움직이기 |
| 관계와 연결 | 「무엇이 무엇에 걸려 있나」 | 들여쓴 목록 | 연결 그래프 · 의존 레일 · 펼침 가지 |
| 불확실성과 범위 | 「얼마나 확실한가 · 어느 범위」 | 숫자 하나 | 범위 띠 · 신뢰 구간이 있는 점 · 흐려지는 미래 구간 |
| 위계와 우선 | 「무엇부터」 | 같은 크기 카드 그리드 | 크기 · 위치가 다른 배치 · 위험도 축 위 정렬 · 맨 위 하나만 크게 |
| 대화와 기록 | 「누가 무엇을 말했나 · 근거는」 | 말풍선 | 근거가 붙은 답 카드 · 인용을 누르면 원문이 옆에 펼쳐짐 · 시간순 사건 줄 |

## 판단을 돕는 한 줄 질문

- 이 숫자는 혼자 의미가 있는가, 다른 숫자와 견줄 때 의미가 있는가 → 후자면 타일을 쪼개지 말고 한 그림에.
- 사용자가 「몇 개」를 세는가, 「어느 것」을 고르는가 → 세면 집계, 고르면 목록이 주인공.
- 지금이라는 기준이 있는가 → 있으면 「지금 선」을 그린다. 앞뒤로 무엇이 놓이는지가 가장 빨리 읽힌다.
- 같은 정보를 두 번 보여 주는가 (표 + 그래프, 배지 + 글자) → 하나로 겹친다.
