# 발명 예시

**데이터의 모양에서 직접 안을 지은 뒤, 막혔을 때만 본다.** 먼저 보면 어느 화면에서나 같은 답이 나와 이 목록이 새 습관이 된다.
예시의 이름과 모양을 그대로 쓰지 않는다. 이 과업의 판단 · 데이터 · 제품 얼굴에 맞게 비틀어 쓴다.
각 예시는 「대체한 기본안 → 새 형태 → 왜 나은가」 순서다.

## 업무 · 운영 화면

**기한 띠 (RiskFuse)**
상태 배지 + 마감일 글자 → 접수부터 기한까지 가로 띠, 지난 만큼 채움 · 남은 날이 적으면 끝이 굵어짐 · 단계 눈금.
목록을 훑기만 해도 「누가 급한가」가 모양으로 보인다.

**단계 레일 (StageRail)**
1 · 2 · 3 스텝퍼 → 단계 폭이 걸린 날수에 비례하는 레일. 막힌 단계는 레일이 끊겨 보인다.
「어디서 오래 걸렸나」가 질문인 화면에 맞다.

**지금 선 레인 (NowLane)**
날짜 칸 정렬 표 → 가운데 「지금」 세로선, 왼쪽은 지난 일 · 오른쪽은 다가올 일. 건마다 한 줄.
오늘 할 일과 이미 늦은 일이 선 하나로 갈린다.

**처리량 흐름 (FlowStrip)**
KPI 타일 네 개(접수 · 검토 중 · 회신 · 반려) → 왼쪽에서 오른쪽으로 흐르는 띠 하나, 갈래마다 폭 = 건수.
숫자끼리 이어진 흐름이 보이고 어디서 새는지 드러난다.

**제자리 펼침 (InlineDrawer)**
행 누르면 모달 → 그 행 아래로 펼쳐지는 상세. 위아래 행과 견주며 본다.

## 데이터 · 판단 화면

**범위 막대 (RangeBar)**
예측값 숫자 하나 → 낮음 · 가능성 높은 구간 · 높음을 한 막대에, 기준선(경보 기준)을 겹쳐.
「기준을 넘을 수도 있나」가 숫자보다 먼저 읽힌다.

**비교 렌즈 (DiffLens)**
이전 · 이번 두 탭 → 한 화면에 겹치고 가운데 손잡이를 밀어 전후를 본다. 바뀐 칸만 밝힌다.

**위험도 축 정렬 (RiskAxis)**
같은 크기 카드 그리드 → 가로축이 위험도, 점 크기가 영향 범위. 맨 오른쪽 위가 먼저 볼 것.

**스파크라인 행 (SparkRow)**
지역별 카드 12장 → 한 줄에 이름 · 7일 추세선 · 지금 값 · 기준 대비 차이. 12줄이 한 화면에 들어온다.
추세가 판단 근거일 때만 쓴다. 추세선에는 기준선을 겹치고 지금 값을 글자로 같이 둔다. 빈자리 채우기용이면 지운다.

## 대화 · AI 화면

**근거 붙은 답 (CitedAnswer)**
말풍선 → 답 문장마다 작은 근거 표식, 누르면 원문 조각이 옆에 펼쳐짐. 믿을지 말지를 그 자리에서 판단한다.

**다음 동작 칩 (NextMoves)**
「더 궁금한 점이 있으신가요?」 → 지금 답에서 이어지는 실제 동작 2~3개(지도에서 보기 · 보고서 열기 · 기준 바꿔 다시 묻기).

**생각 중 줄 (WorkTrace)**
빙글 도는 표시 → 지금 무엇을 찾고 있는지 한 줄씩 쌓이는 진행 줄. 기다리는 이유가 보인다.

## 입력 · 설정 화면

**값을 끌어서 (DragValue)**
숫자 입력칸 + 증감 단추 → 값 자체를 좌우로 끌어 바꿈, 눌러서 직접 입력도 됨. 효과를 바로 미리 본다.

**결과 먼저 설정 (PreviewFirst)**
설정 목록 → 위에 결과 미리보기, 아래 설정을 바꾸면 미리보기가 즉시 따라옴. 설정의 뜻을 결과로 배운다.

**빈 상태 = 첫 동작 (EmptyAction)**
일러스트 + 「데이터가 없습니다」 → 그 자리에 첫 건을 만드는 입력 한 줄, 또는 무엇이 있어야 채워지는지 조건 한 줄.

## 배치

**주인공이 화면을 가진다 (HeroCanvas)**
헤더 + KPI 네 칸 + 카드 그리드 → 주인공(지도 · 타임라인 · 목록) 하나가 화면 대부분, 건수 · 필터 · 동작은 그 가장자리에 얇게 붙는다.
눈이 처음 닿는 곳이 판단할 곳이다.

**축이 바탕인 화면 (AxisStage)**
날짜 칸이 있는 표 → 화면 가로 전체가 시간축, 건은 그 위의 줄. 필터는 축 머리에, 상세는 줄 아래로 펼침.
「언제」를 읽으려고 글자를 해석할 필요가 없다.

**지도 위에 뜨는 판 (FloatingPanes)**
왼쪽 목록 + 오른쪽 지도 반반 → 지도가 화면 전체 바탕, 목록과 상세는 지도 위에 뜬 불투명한 판으로 한쪽 가장자리에. 판을 접으면 지도만 남는다.
공간이 주인공인 화면에서 지도 폭을 반으로 깎지 않는다.

**목록 옆 상세 (SplitFocus)**
목록 → 상세 화면 이동 → 목록 폭을 줄여 왼쪽에 남기고 오른쪽에 상세. 위아래 키로 건을 넘기며 상세가 따라 바뀐다.
여러 건을 차례로 처리하는 일에서 「뒤로 → 다음 건 → 열기」를 없앤다.

**필터를 데이터에 (InlineFilter)**
왼쪽 필터 패널 → 열 머리 · 축 머리를 누르면 그 자리에서 거르기. 걸린 조건은 목록 머리에 꼬리표로 한 줄.
필터 패널이 차지하던 폭을 데이터에 돌려준다.

**비대칭 두 단 (WeightedSplit)**
같은 폭 두 단 → 7 : 3 처럼 한쪽에 무게. 넓은 쪽이 판단, 좁은 쪽이 그 판단의 근거나 동작.
두 단이 같은 폭이면 무엇이 먼저인지 화면이 말해 주지 않는다.
